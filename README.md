# ⚡ Power System Optimization Test Systems v1.0.0

Initial public release of benchmark test systems for constrained power system optimization studies.

---

## 📊 Overview

This repository provides benchmark datasets and test systems commonly used in power system optimization research, including:

- Economic Dispatch (ED)
- Economic Emission Dispatch (EED)
- Unit Commitment (UC)
- Valve-Point Effects (VPE)
- Prohibited Operating Zones (POZ)

The repository is intended for:

- Optimization algorithm benchmarking
- Metaheuristic and evolutionary computation research
- Power system operation studies
- Reproducible computational experiments

---

## 📦 Contents

- Benchmark test systems
- Input datasets
- Constraint configurations
- Supporting documentation
- Reproducible repository structure

---

## 🔍 Data Source

The benchmark test systems in this repository are based on:

> Al-Roomi, A.R. (2016). *Economic Load Dispatch Test Systems Repository*. Dalhousie University, Electrical and Computer Engineering, Halifax, Nova Scotia, Canada. https://www.al-roomi.org/economic-dispatch

---

## 🔍 Applications

The test systems can be used for studies involving:

- Classical optimization methods
- Swarm intelligence algorithms
- Evolutionary algorithms
- Hybrid optimization techniques
- Constraint-handling strategies
- Economic and environmental dispatch

---

## ⚙️ Supported Constraints

Included benchmark cases may involve:

- Generator limits
- Ramp-rate limits
- Power balance constraints
- Spinning reserve constraints
- Valve-point loading effects
- Prohibited operating zones
